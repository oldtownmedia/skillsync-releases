# SkillSync releases

Signed and notarized SkillSync installers for Apple Silicon Macs (M1 and later). SkillSync syncs OTM's skills into Claude Code and Codex.

This repo only holds release files. The source code is private.

## Install

1. Download the latest `SkillSync_*_aarch64.dmg` from [Releases](https://github.com/oldtownmedia/skillsync-releases/releases/latest).
2. Open the `.dmg` and drag **SkillSync** to Applications.
3. Open **SkillSync** from Applications.

Or run:

```bash
curl -fsSL https://raw.githubusercontent.com/oldtownmedia/skillsync-releases/main/install.sh | bash
```

Once installed, SkillSync updates itself.
